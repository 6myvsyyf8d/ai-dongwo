# 记录采集矩阵表单 — 设计文档

**日期**: 2026-07-30
**状态**: 已确认

## 背景

当前记录页像流水账：自由文本为主，缺乏结构化引导，记录质量参差不齐。本次重构将记录采集改为「矩阵导航 + 轻量表单」模式，降低录入门槛，提升数据一致性。

## 设计决策

### 1. 矩阵导航（方案 A）

模块 × 记录类型交叉矩阵，点击有意义的格子进入对应表单。不合理的组合（如"情绪行为×医疗记录"）置灰不可点击。

**矩阵结构**:

| 模块 \ 类型 | 观察 | 日常照护 | 事件 | 成就 | 医疗 | 偏好 |
|---|---|---|---|---|---|---|
| 情绪行为 | ✓ | ✓ | ✓ | — | — | ✓ |
| 沟通说明书 | ✓ | ✓ | ✓ | ✓ | — | ✓ |
| 照护医疗 | ✓ | ✓ | ✓ | — | ✓ | — |
| 工作支持 | ✓ | ✓ | ✓ | ✓ | — | ✓ |

### 2. 表单内容

底部弹出（iOS Sheet 风格），包含：

| 区域 | 内容 |
|---|---|
| 上下文 | 模块标签 + 类型标签（只读展示） |
| 输入方式 | 🎤 语音 / ✍️ 打字手写（Tab 切换，默认语音） |
| 快捷标签 | 按模块动态渲染，多选 |
| 提交 | 提交按钮 |

**不包含**:
- 星星评分 → 用标签替代，更轻量
- 可见性设置 → 由系统级角色可见性配置决定，不在记录层面重复

### 3. 标签按模块动态变化

| 模块 | 标签池 |
|---|---|
| 情绪行为 | 平静、愉悦、低落、焦虑、兴奋、易怒、配合、抗拒 |
| 沟通说明书 | 主动表达、被动回应、清晰、模糊、肢体语言、辅助沟通 |
| 照护医疗 | 按时服药、拒绝服药、睡眠良好、睡眠不佳、食欲正常、身体不适 |
| 工作支持 | 独立完成、需要提示、需要协助、专注、分心、完成质量高、速度正常 |

### 4. 语音输入

- 按钮尺寸：48px（非全屏大按钮）
- 点击开始录音，按钮变红并脉冲动画
- 识别完成后文字显示在结果区域
- 可重新录音覆盖

### 5. 数据存储

记录数据结构沿用现有 `storage.js` 的 `addRecord`，新增字段：
- `tags: string[]` — 选中的标签列表
- `inputMode: 'voice' | 'write'` — 记录输入方式（用于后续分析）
