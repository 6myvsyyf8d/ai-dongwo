# 分析页 & 权限展示 设计文档

**日期**: 2026-07-31 | **状态**: 已确认

## 1. 我的权限 — 模块能力清单

### 目标
将管理页「授权状态」区块从"授权人信息"改为"功能权限清单"，让用户一眼看清自己能做什么。

### 设计
- 标题：`🔓 我的权限`
- 每行显示模块图标 + 模块名 + 权限标签
- 权限标签：只读=灰色`查看`，可写=模块色`查看 · 记录`
- 权限判断来自 `Permissions` 模块的 `canRead`/`canWrite` 及各模块 scope
- 移除授权人姓名、有效期等元信息

### 涉及文件
- `js/app.js` — `showManagement` 函数中授权状态区块
- `css/main.css` — 新增 `.perm-module-list` 样式

---

## 2. 洞察关联记录 — 证据链

### 目标
将原始记录列表从"数据罗列"改为"洞察证据"，每条 AI 解读下面挂相关记录作为支撑。

### 设计
- 每条洞察是可折叠卡片，展开后显示关联记录
- 记录行：日期 + 模块图标 + 内容摘要
- 异常/负面记录用红色左侧边线，正面记录用绿色
- 记录按时间倒序排列，最多显示 5 条

### 涉及文件
- `js/analytics-ui.js` — `_renderMonthlyTab` 中的 AI 解读区块，新增 `_renderInsightEvidence` 函数
- `js/analytics-engine.js` — 扩展 `monthlyReport` 返回每条洞察的关联记录 ID 列表
- `css/analytics.css` — 新增 `.insight-card`、`.insight-evidence` 样式

---

## 3. 月度概览 — 结构化数据卡片

### 目标
将纯文本概览改为结构化卡片，信息层级清晰。

### 设计
- 顶部 4 个统计卡片（总记录 / 日均 / 记录天数 / 覆盖模块）
- 中间 AI 解读列表（带图标的多行洞察）
- 底部可折叠数据详情
- 统计卡片使用暗色背景 + 微妙发光边框

### 涉及文件
- `js/analytics-ui.js` — `_renderMonthlyTab` 中概览区块
- `css/analytics.css` — 新增 `.monthly-stats-grid`、`.monthly-stat-card` 样式

## 4. 全局图标系统 — 星座线描风格

### 目标
用自定义 SVG 星座线描图标替换所有 emoji 图标，统一深空星图美学。

### 设计
- 风格：细线描边（1.2px）+ 微光晕，宇宙蓝 `#8ab8e8` 为主色，各模块用对应色
- 每个模块/功能对应一个独特的几何象形符号
- 所有图标集中定义，通过 CSS class 或 inline SVG 使用

### 图标清单
| 用途 | 符号 | 颜色 |
|------|------|------|
| 沟通说明书 | 对话气泡 + 星点连线 | #9B85B8 |
| 情绪与行为 | 波浪线 + 圆心 | #D4877B |
| 照护与医疗 | 十字 + 光环 | #A8C9A0 |
| 工作与生活 | 六边形 + 内部星点 | #D4A85A |
| 关系地图 | 三圆交叠 | #B5A8D4 |
| 首页 | 房子轮廓 + 星点 | #8ab8e8 |
| 记录 | 竖线 + 横线（笔记本） | #8ab8e8 |
| 档案 | 星形轮廓 | #8ab8e8 |
| 管理 | 齿轮轮廓 | #8ab8e8 |
| 分析 | 折线 + 星点 | #8ab8e8 |
| 权限/锁 | 锁形轮廓 | #8ab8e8 |
| 搜索 | 放大镜轮廓 | #8ab8e8 |
| 关闭 | 交叉线 | #a0a0b8 |
| 箭头 | 单线箭头 | #a0a0b8 |

### 实现方式
- 创建 `css/icons.css` 统一管理所有图标样式
- 使用 inline SVG 或 CSS `::before` 伪元素 + `mask-image`
- 保持 `< 2KB` 总体积，避免性能影响
- 底部导航 4 个图标优先替换，验证效果后再推广

### 涉及文件
- `css/icons.css` — 新建，全局图标样式
- `index.html` — 引入 `icons.css`
- `js/app.js` — 底部导航 `renderBottomNav` 中图标替换
- 逐页面替换 emoji 为 SVG 图标
